# TOUCH

Учебный командный проект (группа ИС-41): сайт молодого немецкого бренда одежды и аксессуаров TOUCH.

**Версия:** 1.1 (после тестирования 02.10.2026, повторная проверка 04.10.2026)

- Репозиторий: 

## Страницы

| Страница | Файл | Что на странице |
| --- | --- | --- |
| Главная | `index.html` | Hero со слоганом и CTA, плитки категорий, «О бренде» |
| Каталог | `catalog.html` | Поиск, фильтры (цена, цвет, пол, сезон), 8 товаров |
| Карточка товара | `product.html` | Галерея, характеристики, уход, цена, отзывы |
| Контакты | `contacts.html` | Контакты, форма обратной связи |
| Вход | `login.html` | Вход, вход гостем |

## Технологии

- HTML5, семантическая разметка (header, nav, main, section, article, footer)
- CSS3: переменные (`:root`), Flexbox, Grid, БЭМ, три брейкпоинта (1024+, 768–1023, 320–767)
- Шрифты: Inter и Zalando Sans Expanded (Google Fonts)

## Структура

```
index.html, catalog.html, product.html, contacts.html, login.html
favicon.svg
css/style.css
img/            логотипы, hero, плитки, products/, gallery/
```

## Запуск

Откройте `index.html` в браузере или используйте Live Server в VS Code. Сборка не нужна. Для шрифтов требуется интернет.

## Качество

- Горизонтального скролла нет на ширинах 320–1440 px
- Контраст текста соответствует WCAG AA (в том числе текст на фото)
- Вес главной страницы ≈ 1 МБ (без веб-шрифтов)
- Результаты официальных валидаторов и Lighthouse — в отчёте тестировщика

## Ограничения

- Корзина, оформление заказа, избранное и регистрация не реализованы (демонстрационный режим: счётчик и уведомления)
- Страница товара одна (худи Siniy Vsadnik); кнопки «Подробнее» в каталоге ведут на неё
- Фильтр «Пол»: в каталоге нет мужских товаров, поэтому «Женский» показывает все позиции
- Права на фотографии не подтверждены: перед публичной публикацией заменить или подтвердить (реестр изображений)
